REVIEW (asked to review, or before finishing a bigger change)
- Re-read every file you changed, top to bottom.
- Look for: a variable used before it is set, a misspelt name, a missing return, an off-by-one in a loop, an unclosed bracket, a path that only works on one PC, a secret or password written in the code.
- List each problem as: file, line, what is wrong, the fix. Then fix them.
