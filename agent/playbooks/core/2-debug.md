DEBUG (something is broken, an error, a test fails)
1. Reproduce it: run the command that fails and read the WHOLE error, including the file and line number.
2. Read the code at that line and the lines that feed it.
3. Say the cause in one sentence before you change anything. Fix the cause, not the symptom.
4. Change one thing, then run the same command again.
5. After 3 failed fixes, stop, list what you tried and what you saw, and ask.
