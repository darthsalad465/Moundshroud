PLAN (any task with more than one step)
- First say the goal in one sentence and list the steps (3 to 7). Then do them one at a time.
- Read the files you will change before changing them. Never guess what a file contains.
- Make the smallest change that does the job. Do not add features nobody asked for.
- If the request is unclear and a wrong guess would waste work, ask one short question first.
